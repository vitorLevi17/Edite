## Descrição

O EDITE é um sistema projetado para armazenar e editar imagens. Nosso objetivo é criar um ambiente simples e objetivo na hora de realizar edições de imagens e que as pessoas possam compartilhar com nossa rede suas fotos e postagens.

## Funcionalidades

- **Cadastro de Usuários:** Permite que os usuários se registrem no sistema.
- **Armazenamento de imagens** Os usuarios tem suas fotos gravadas no sistema.
- **Compartilhamento com a rede** Os usuarios podem ver as fotos de outros usuarios.
- **Edições - Preto e Branco:** É possível deixar a foto em preto e branco e assim já deixa-la salvo no banco.
- **Edições - Remover fundo da imagem** Essa funcionalidade remove o fundo da foto, deixando apenas o principal e com um fundo preto.
- **Edições - Inverter lados:** É possível deixar inverter o lado da foto sem que ela fique estranha.
- **Interface Intuitiva:** Design amigável que facilita a navegação e o uso da plataforma.

## Tecnologias Utilizadas

- **Backend:** Python, Flask
- **Frontend:** HTML, CSS, JavaScript
- **Banco de Dados:** SQLite / DB browser
- **Outros:** Bootstrap
